# Screenshots Directory

## Instructions for Tester

This directory is designated for storing manual testing screenshot evidence and bug attachments captured during test execution on [SauceDemo](https://www.saucedemo.com/).

### Recommended File Naming Conventions:
- **Defects / Bug Attachments**: `BUG_001_login_locked_out_error.png`
- **Pass Execution Verification**: `TC_CHK_009_order_confirmation_pass.png`
- **UI Anomaly Evidence**: `BUG_002_problem_user_broken_images.png`

---
*Keep screenshots clear, organized, and relevant for portfolio presentation.*
